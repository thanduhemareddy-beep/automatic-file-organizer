
# Automatic File Organizer

## About
A beginner-friendly Python automation project that
organizes files into folders based on file extensions.

## Features
- Automatically detects file extensions
- Creates folders automatically
- Organizes PDFs, images, videos, audio and documents
- Handles duplicate filenames without overwriting
- Handles file operation errors

## Technologies Used
- Python 3
- pathlib
- os concepts
- shutil

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

   python main.py

4. Enter the folder path you want to organize.
